# 🏗️ سیویل‌دسک (CivilDesk)

دستیار هوشمند شخصی برای مهندس عمران: وظایف روزمره، پروژه‌ها، گزارش روزانه‌ی کارگاه، صورت‌وضعیت‌ها،
دریافت و پرداخت، مخاطبین و یادداشت‌ها در یک جا؛ هم از طریق **برنامه‌ی وب فارسی** و هم **ربات تلگرام**،
با یک **دستیار هوش مصنوعی (Claude)** که با زبان طبیعی همه‌چیز را ثبت و پیگیری می‌کند.

## امکانات

| بخش | کارها |
|---|---|
| **داشبورد** | کارهای عقب‌افتاده، امروز و هفت روز آینده · پیشرفت و روزهای باقی‌مانده‌ی پروژه‌ها · هشدار ثبت‌نشدن گزارش روزانه · صورت‌وضعیت‌های منتظر پرداخت · جمع دریافت/هزینه‌ی ماه |
| **وظایف** | اولویت، مهلت، ساعت، دسته (کارگاه، جلسه، مکاتبه، شخصی)، اتصال به پروژه، **یادآوری در تلگرام** |
| **پروژه‌ها** | کارفرما، پیمانکار، مشاور، نقش شما، مبلغ قرارداد، تاریخ شروع و پایان، درصد پیشرفت؛ خلاصه‌ی پیشرفت فیزیکی و زمانی |
| **گزارش روزانه** | آب‌وهوا، نیروی انسانی، ماشین‌آلات، مصالح ورودی، کارهای انجام‌شده، مشکلات، دستورات |
| **صورت‌وضعیت** | موقت/قطعی/تعدیل، ناخالص، کسورات، خالص (خودکار)، مبلغ تأییدشده و پرداختی، روزهای انتظار |
| **دریافت و پرداخت** | درآمد و هزینه به تفکیک پروژه و دسته، مانده |
| **مخاطبین و یادداشت‌ها** | شماره‌ها، سمت‌ها، یادداشت‌های برچسب‌دار |
| **اسناد و پرسش 📚** | PDF (متنی یا اسکن‌شده)، عکس، Word و متن را بارگذاری کنید و سؤال بپرسید؛ مرتبط‌ترین بندها با **نام سند و شماره‌ی صفحه** نمایش داده می‌شوند و صفحه‌ی اصلی با یک کلیک دیده می‌شود (جزئیات پایین‌تر). |
| **دستیار 🤖** | «فردا ساعت ۱۰ بازدید آرماتوربندی سقف سوم پروژه ولیعصر، یک ساعت قبلش یادم بنداز» → خودش وظیفه و یادآوری را می‌سازد. گزارش روزانه را از متن آزاد ثبت می‌کند، خلاصه‌ی پروژه و وضعیت مالی می‌دهد، نامه و صورتجلسه می‌نویسد. |
| **تلگرام** | گفتگو با همان دستیار، `/today` خلاصه‌ی امروز، `/tasks` وظایف باز، یادآوری‌ها و **گزارش صبحگاهی خودکار** |

همه‌ی تاریخ‌ها **شمسی** هستند و داده‌ها در یک فایل SQLite روی سرور خودتان ذخیره می‌شوند.

## اسناد و پرسش 📚

برای هر صفحه‌ی PDF، برنامه خودکار بهترین روش خواندن را انتخاب می‌کند:

1. **لایه‌ی متنی PDF** خوانده و حروف شکل‌دار فارسی و متن‌های برعکس اصلاح می‌شوند.
2. اگر صفحه **اسکن‌شده** بود یا متنش **خراب** (مشکل رایج PDFهای فارسی)، صفحه با **OCR** (Tesseract) خوانده می‌شود؛
   اول با مدل فارسی و اگر صفحه انگلیسی بود، خودکار با مدل انگلیسی.
3. متن به بندهای کوتاه با شماره‌ی صفحه تقسیم و دو نوع نمایه ساخته می‌شود:
   - **کلیدواژه‌ای** (با یکسان‌سازی ی/ي، ک/ك، نیم‌فاصله، ارقام و پسوندهای رایج)
   - **معنایی** با مدل چندزبانه‌ی `multilingual-e5-small` که روی CPU و **بدون اینترنت** کار می‌کند
     (مثلاً «کاور آرماتور» بند «پوشش بتن روی میلگردها» را هم پیدا می‌کند)
4. نتیجه‌های دو روش ترکیب و مرتب می‌شوند.

**پاسخ:** بدون هیچ سرویس خارجی، مرتبط‌ترین جمله‌ها عیناً از متن اسناد با شماره‌ی منبع نمایش داده می‌شوند.
اگر مدلی در دسترس باشد، پاسخ نوشته هم می‌گیرید: Claude (با `ANTHROPIC_API_KEY`) یا هر مدل سازگار با OpenAI،
مثلاً مدل متن‌باز روی Ollama خودتان (`CIVILDESK_LLM_BASE_URL`).

**محدودیت‌ها:** OCR فارسی خطا دارد، به‌خصوص در اعداد (مثلاً «۵» گاهی «۰» خوانده می‌شود)، جدول‌ها و فرمول‌ها.
کنار نتیجه‌های OCR برچسب «OCR» می‌آید؛ **اعداد را با دکمه‌ی «دیدن صفحه‌ی اصلی» چک کنید.**
سرعت OCR حدود ۱ تا ۳ ثانیه برای هر صفحه است (کتاب اسکن‌شده‌ی ۵۰۰ صفحه‌ای ≈ ۱۰ تا ۳۰ دقیقه، در پس‌زمینه).
PDFهای متنی سالم تقریباً فوری پردازش می‌شوند.

روی ویندوز بدون Docker، برای خواندن فایل‌های اسکن‌شده باید Tesseract را با زبان فارسی نصب کنید؛
بدون آن، PDFهای متنی کار می‌کنند.

## راه‌اندازی سریع

```bash
git clone <آدرس مخزن> civildesk && cd civildesk
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # و مقادیر را پر کنید
uvicorn civildesk.main:app --host 0.0.0.0 --port 8000
```

سپس `http://localhost:8000` را باز کنید.

### تنظیمات مهم (`.env`)

- `ANTHROPIC_API_KEY` — کلید API از [console.anthropic.com](https://console.anthropic.com). بدون آن، همه‌ی بخش‌ها جز دستیار کار می‌کنند.
- `CIVILDESK_PASSWORD` — اگر برنامه روی اینترنت است **حتماً** رمز بگذارید (مرورگر نام کاربری/رمز می‌خواهد؛ نام کاربری مهم نیست).
- `CIVILDESK_CURRENCY` — واحد پول (پیش‌فرض ریال؛ دستیار «تومان» را خودش تبدیل می‌کند).

### ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید، `/newbot` بزنید و توکن را در `TELEGRAM_BOT_TOKEN` بگذارید.
2. برنامه را اجرا کنید، به ربات خودتان `/id` بفرستید و عدد برگشتی را در `TELEGRAM_ALLOWED_CHAT_IDS` قرار دهید.
3. برنامه را دوباره اجرا کنید. حالا فقط شما به ربات دسترسی دارید.

ربات همراه وب‌سرور اجرا می‌شود (نیازی به دامنه یا وبهوک نیست). اگر فقط ربات را می‌خواهید: `python -m civildesk.telegram_bot`.

> ⚠️ uvicorn را با **یک worker** اجرا کنید؛ چند worker یعنی چند ربات هم‌زمان و پیام‌های تکراری.

## استقرار روی سرور

دسترسی به API کلود و تلگرام از داخل ایران محدود است، پس برنامه را روی یک **سرور مجازی خارج از ایران** اجرا کنید
(یا روی سرور، پراکسی را با متغیرهای `HTTPS_PROXY` تنظیم کنید). با Docker:

```bash
docker build -t civildesk .
docker run -d --name civildesk --restart unless-stopped \
  --env-file .env -p 8000:80 -v civildesk-data:/data civildesk
```

برای HTTPS یک reverse proxy مثل Caddy یا Nginx جلوی آن بگذارید.

**پشتیبان‌گیری:** فایل `data/civildesk.db` را کپی کنید، یا از `/api/export` خروجی JSON کامل بگیرید.

## ساختار کد

```
civildesk/
  config.py        تنظیمات از متغیرهای محیطی
  jalali.py        تبدیل تاریخ شمسی ↔ میلادی
  db.py            تعریف موجودیت‌ها + ایجاد/ویرایش/جستجو روی SQLite
  services.py      داشبورد، خلاصه‌ی پروژه، گزارش مالی، گزارش صبحگاهی، یادآوری‌ها
  agent.py         دستیار Claude و ابزارهایش (از روی تعریف موجودیت‌ها ساخته می‌شوند)
  textnorm.py      یکسان‌سازی متن فارسی، تشخیص متن خراب یا برعکس
  documents.py     دریافت اسناد، استخراج متن و OCR، نمایه‌سازی و جستجوی ترکیبی
  embedder.py      مدل جستجوی معنایی (ONNX روی CPU)
  llm.py           نوشتن پاسخ از روی اسناد (Claude / مدل سازگار با OpenAI / استخراجی)
  telegram_bot.py  ربات تلگرام و زمان‌بند یادآوری
  main.py          وب‌سرور FastAPI
  static/          رابط کاربری وب (بدون نیاز به build)
tests/             آزمون‌ها: pip install -r requirements-dev.txt && pytest
```

**افزودن یک بخش جدید** (مثلاً «ماشین‌آلات» یا «مکاتبات»): کافی است یک `Entity` در `ENTITIES` داخل `db.py`
تعریف کنید و یک تب در `TABS` فایل `static/app.js` اضافه کنید؛ جدول پایگاه داده، API، فرم وب و ابزارهای دستیار
خودکار ساخته می‌شوند. ستون‌های جدید هم در اجرای بعدی خودکار به جدول‌های موجود اضافه می‌شوند.

## قدم‌های بعدی پیشنهادی

- دریافت پیام صوتی و عکس در تلگرام (مثلاً عکس فاکتور یا صورتجلسه و استخراج خودکار اطلاعات)
- تولید PDF گزارش روزانه/هفتگی با سربرگ
- اتصال به تقویم گوگل و ایمیل
- نمودار پیشرفت برنامه‌ای در برابر واقعی (S-Curve) برای هر پروژه
